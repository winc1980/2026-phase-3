# Phase 3 の進め方

## チーム開発



## ふだん：家/部室で開発
#### タスクを取る
チームにとって優先順位が高いタスクの中で、自分にできそうなものを選びます。
同時に進めるのは1個だけです。難しすぎたり、他のタスクを待つ必要があって詰まった時は、すぐにチームメイトに相談しましょう。

#### 実装する
自力で調べて、頑張って実装してください。AIに相談してもOKです。
それでも分からないときは、部室でメンターに聞くか、discordでメンターをメンションして相談してください。

#### PR(プルリクエスト)を出す
動作確認をして、チームメイトのための説明文を書きましょう。


## 通常活動日（毎週）：もくもく会
チームのみんなで集まって開発をします。
みんなの進捗を反映させた状態で動作確認をし、開発状況のすり合わせをしましょう。

## 通常活動日（月末）：LT会
通常活動の冒頭で、チームごとに短い発表をします。
見てほしい進捗、聞いてほしい開発エピソードなどを全員で共有しましょう。


# AI利用ポリシー
今回から、AIの利用を条件付きで容認します。

### 条件
- コードを生成させるのではなく、相談相手として利用すること：[AIメンター](#AIメンター)

AIメンターとしてAIを使う場合でも、**最終的にコードに責任を持つのは自分自身**だということを忘れないでください。 
AIが教えてくれたコードが何をしているのかを理解し、どんな結果をもたらすのかをよく考え、**チームメイトに説明できるように**しておいてください。 
誰も理解していないコードが積み上がることがないように、チームメイトとよく相談して、計画的に運用してください。

## AIメンター
2種類の方法を案内します。

課金していない人：[ChatGPTメンター.md](ChatGPTメンター.md)
無料版のChatGPTに自分のレポジトリの情報を与えて相談する方法を案内します。

AIに課金している人：
このままコーディングAIを開いてください。AIメンター[AIメンター.md](/AI_mentor.md)が自動的に適用されます。
適用を外したい場合はAGENTS.mdの2行目を削除してください。

# この学習のゴール

### プロジェクト経験：開発全体を見通す視点を身に付ける
- 開発プロジェクト全体を経験すること
- チームでタスクとスケジュールの状況を共有し、計画的に開発を進めること
- 春休みの時点で、実ユーザーを抱えるプロジェクトに参加できる状態になること

### エンジニアとしての自立：自走力をつける
- issue作成->優先順位付け->issue着手->PR提出->レビュー->マージまでの一連の流れを回せるようになること
- 分からないことを自分で調べて解決できるようになること
- AIを活用し、うまくいった経験、いかなかった経験の両方から教訓を得ること
