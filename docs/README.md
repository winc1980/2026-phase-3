# Phase 3 進め方



## ふだん：家/部室で開発
- タスクを取る
    チームにとって優先順位が高いタスクの中で、自分にできそうなものを選びます。
    同時に進めるのは1個だけです。難しすぎたり、他のタスクを待つ必要があって詰まった時は、すぐにチームメイトに相談しましょう。
- 実装する
AIを使っていいので、自力で調べて、自力で頑張って実装してください。
AIに聞いても分からないときは、部室のメンターに聞くか、discordでメンターをメンションして相談してください。
- 動作確認をする


## 通常活動日（毎週）：もくもく会
チームのみんなで集まって開発をします。
みんなの進捗を反映させた状態で動作確認をし、開発状況のすり合わせをしましょう。

## 通常活動日（月末）：LT会
チームごとに短い発表をします。
見てほしい進捗、聞いてほしい開発エピソードなどを全員で共有しましょう。

LT会の後、残った時間でもくもく会に入ります。その月の進捗を振り返って、次の月の計画を立てましょう。


## AIの使い方
AIの利用を推奨します。

まずは、自分のコードを見てもらう相談相手としての利用をお勧めします。[AIメンター]
ただし、AIを使う際は、**最終的にコードに責任を持つのは自分自身**だということを忘れないでください。
AIが教えてくれた/生成してくれたコードが何をしているのか、どんな結果をもたらすのかを理解し、**チームメイトに説明できるように**しておいてください。無責任にAI生成を乱用すれば、誰も理解していないコードが積み上がり、プロジェクトは崩壊に向かいます。
チームメイトとよく相談して、計画的に運用してください。

## AIメンター
2種類の方法を案内します。

AIに課金している人：
AIメンターの導入方法を案内します。

課金していない人：
無料版のChatGPTに自分のレポジトリの情報を与えて相談する方法を案内します。


# この学習のゴール

## プロジェクト経験
- 開発プロジェクト全体を経験すること
- チームでタスクとスケジュールの状況を共有し、計画的に開発を進めること
- 春休み～来年度には、実ユーザーを抱えるプロジェクトに参加できる状態になること

## エンジニアとしての自立
- issue作成->優先順位付け->issue着手->PR提出->レビュー->マージまでの一連の流れを回せるようになること
- 分からないことを自分で調べて解決できるようになること
- AIを活用し、うまくいった経験、いかなかった経験の両方から教訓を得ること
