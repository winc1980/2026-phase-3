
# 無料版ChatGPTメンター

## 始め方

1. 無料版ChatGPTをwebで開く

2. GitHubのアドオンを入れてアカウント連携をする
これで自分のチームのレポジトリを読んでくれます

3. phase3専用のChatGPTのprojectを作る
これでレポジトリのこと、前の会話の内容を記憶してくれます。

4. AGENTS.mdを読ませる
メモリに自分のチームのレポジトリのAGENTS.mdのリンクを入れます。

### 2. レビュー

### 3. トラブルシューティング
