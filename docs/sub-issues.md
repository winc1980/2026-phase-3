# 1.sub-issueってなに？

1つのissueの下に、小さいissueをぶら下げられる機能です。
上のissueを **親issue**、ぶら下がっているissueを **子issue** と呼びます。

```
親：Next.jsを導入する                 ← 2/4 完了
 ├ 子：環境構築: Next.js（Aさん）  ✅
 ├ 子：環境構築: Next.js（Bさん）  ✅
 ├ 子：環境構築: Next.js（Cさん）
 └ 子：環境構築: Next.js（Dさん）
```

親issueには子issueがいくつ終わったかが表示されるので、「全体のどこまで進んだか」がひと目で分かります。

# 2.技術導入タスクを立てる

チームで使うと決めた技術を、**全員が自分のPCで使える状態にする**ためのタスクです。

## 2.1.親issueを作る

1. Issues → New issue → 「タスク」テンプレートを選ぶ
2. 次のように書く

| 項目       | 書くこと（例）                         |
| ---------- | -------------------------------------- |
| タイトル   | Next.jsを導入する                      |
| やること   | チーム全員がNext.jsを使える状態にする  |
| 完了の条件 | 全員分の環境構築issueがcloseされている |

使う技術が複数あるなら（例：言語とデータベース）、技術ごとに親issueを作ります。

## 2.2.子issueを作る

メンバー1人につき1つ、環境構築issueを作ります。

1. Issues → New issue → 「環境構築」テンプレートを選ぶ
2. タイトルを「環境構築: Next.js（自分の名前）」にして、技術の欄を書いて作成する
3. 右側の **Assignees** で、自分をアサインする
4. 親issueを開き、本文の下の **Create sub-issue ▾** → **Add existing issue** から、いま作ったissueを選ぶ

今日来ていないメンバーの分も作っておきましょう。
本人にアサインして、Discordでメンションしておけば、何をすればいいかがすぐ伝わります。

## 2.3.環境構築を進める

- **最初に取り組む人**は、手順書がない状態で自分で調べることになります。やったことを、issueの「メモ」欄にどんどん書いておきましょう。それがそのまま、あとの人の手順書になります。
- **あとから取り組む人**は、先に終わった人のissueのメモを読んでから始めましょう。
- 終わったら、完了の条件にチェックを入れてcloseします。

全員の子issueがcloseされたら、親issueもcloseしましょう。

> **第2週はここまででかまいません。**
> 環境構築を先に済ませて、続きはまた来週やりましょう。

# 3.実装タスクを立てる

作りたい機能を、**1人が1週間で取り組める大きさ**の子issueに分けます。
分け方は [プロジェクト進行.md の「3.2.タスクを分割する」](プロジェクト進行.md#32タスクを分割する) を見てください。

## 3.1.対象にする親issue

優先順位が **Must** の機能の親issueだけを分けます。
Should、Couldは、Mustが終わってから分ければ十分です。

## 3.2.子issueを作る

親issueを開き、**Create sub-issue** から作ります。テンプレートは「タスク」を使います。

例：

```
親：ホーム画面を表示する
 ├ 子：画面の枠（ヘッダーとフッター）を作る
 ├ 子：おすすめ一覧を仮データで表示する
 └ 子：一覧の1件をタップしたら詳細画面に移る
```

## 3.3.依存するタスクを書く

「このタスクは、あのタスクが終わらないと始められない」というときは、本文に **#番号** で書いておきます。

```
依存するタスク：#12
```

`#12` はissue 12へのリンクになります。リンク先がcloseされたら、着手してOKの合図です。

# よくある疑問

### 子issueの下に、さらに子issueを作ってもいい？

できますが、親と子の2段までにしておくのがおすすめです。段が深いと、どこに何があるか分からなくなります。

### 親issueは誰にアサインする？

その機能・技術の取りまとめ役を1人アサインしましょう。子issueが全部終わったかを見て、親issueをcloseする人です。
